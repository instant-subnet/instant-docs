Official documentation

Inference infrastructure miners can run and validators can inspect.

Instant connects chain-registered GPU operators to an OpenAI-compatible inference gateway, records signed delivery evidence, and gives validators a bounded path from observed work to scores.

Installer availability

The public miner installer is not published yet. Do not run an unofficial installer, and never give a seed phrase, private coldkey, or wallet file to a website or support contact.

The serving path

One request, four explicit boundaries

  1. Accept

    The platform authenticates an OpenAI-compatible request and assigns a unique request ID.

  2. Route

    Only a connected, ready miner whose submitted UID/hotkey pair passed platform onboarding and is not on hold is eligible.

  3. Serve

    The worker streams the completion through the platform immediately, then returns a receipt and TOPLOC evidence.

  4. Verify and score

    The verifier asynchronously returns a pass/fail assertion. The platform applies hold policy, and validators consume completed platform metrics.

Trust model

Know what each signal proves

Hotkey identity

A signed onboarding challenge proves control of a registered operational hotkey. The chain supplies the current UID binding.

Signed receipts

A receipt binds a worker identity to request and response commitments and observed delivery metrics. It is not, by itself, a model proof.

TOPLOC evidence

TOPLOC asynchronously checks supported inference evidence. The verifier only asserts pass or fail; the platform decides whether to hold a miner.

Current boundaries

Conservative by design

  • The public Miner Kit is unavailable; no public installation command is supported.
  • Workers initiate outbound TLS WebSocket connections; miners do not need to expose an inference port.
  • Customer output streams immediately; TOPLOC verification happens asynchronously and affects subsequent routing.
  • The validator defaults to a 100% burn vote. Report-based scoring is a separate, explicitly configured mode.
